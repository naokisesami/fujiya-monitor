# フジヤエービック 在庫監視ツール

出品中の商品がフジヤエービック上で売り切れたら、メールで通知します。
GitHub Actions を使って30分おきに自動でクラウド上でチェックします（PCを起動しっぱなしにする必要はありません）。

## できること（現状）
- フジヤエービックの商品ページを定期巡回し、在庫状況をチェック
- 「在庫あり → 売り切れ／ページ削除」を検知したらメールで即通知

## できないこと（今後の拡張）
- eBayの出品を自動で取り下げる／在庫を0にする、はまだ含まれていません。
  これには eBay Developer アカウントとAPIキーが必要です。取得され次第、
  この仕組みに「自動更新」機能を追加できます。

## セットアップ手順

### 1. GitHubアカウント作成・リポジトリ作成
1. https://github.com で無料アカウントを作成（すでにお持ちならスキップ）
2. 右上の「+」→「New repository」で新規リポジトリを作成
   - Public でも Private でも可（Privateの場合、無料枠は月2,000分。今回の頻度なら十分収まります）
3. このフォルダ一式（products.csv, monitor.py, requirements.txt, state.json, .github フォルダ）を
   そのリポジトリにアップロードします（GitHubの「Add file」→「Upload files」でドラッグ&ドロップでOK）

### 2. Gmailアプリパスワードの取得
通知メールはGmail経由で送信します。
1. 通知に使いたいGoogleアカウントで https://myaccount.google.com/apppasswords を開く
   （2段階認証を有効にしていないと表示されないので、先に2段階認証をONにしてください）
2. アプリ名を適当に入力（例：fujiya-monitor）して生成
3. 表示された16桁のパスワードをコピーしておく（スペースは含めても含めなくてもOK）

### 3. GitHubにシークレット（認証情報）を登録
リポジトリの Settings → Secrets and variables → Actions → 「New repository secret」で以下を登録：

| Name | Value |
|---|---|
| `GMAIL_USER` | 通知に使うGmailアドレス |
| `GMAIL_APP_PASSWORD` | 手順2で取得した16桁のアプリパスワード |
| `NOTIFY_TO` | 通知を受け取りたいメールアドレス（自分宛でもOK） |

### 4. 監視したい商品を登録
`products.csv` を編集し、行を追加します。

```
fujiya_url,ebay_item,memo
https://www.fujiya-avic.co.jp/shop/g/g240001179986/,https://www.ebay.com/itm/xxxxxxx,Cayin N7
```

- `fujiya_url`：フジヤエービックの商品ページURL（必須）
- `ebay_item`：対応するeBayの出品URL（通知メールに表示されるだけ。空欄でも可）
- `memo`：商品名など、自分がわかるメモ

GitHub上で直接編集する場合は、products.csv を開いて鉛筆アイコン（Edit）から編集→コミットでOKです。

### 5. Actionsを有効化して動作確認
1. リポジトリの「Actions」タブを開く
2. 「Fujiya Avic Stock Monitor」ワークフローを選択
3. 「Run workflow」ボタンで手動実行し、正常に動くか確認
   - エラーが出る場合は、Actionsのログでエラー内容を確認してください
4. 問題なければ、あとは30分おきに自動実行されます

## 運用上の注意点

- **GitHubの仕様で、60日間リポジトリへの操作（コミット等）がないとスケジュール実行は自動停止**します。
  この仕組みは毎回 state.json をコミットするため通常は問題ありませんが、
  もし止まっていたら Actions タブから手動で再度有効化してください。
- 中古品は「フジヤエービックが在庫あり表示のままでも、実は店頭で完売済み」というケースが
  フジヤエービック自身の注意書きにもある通りまれにあります（Web在庫と実在庫にタイムラグがある場合）。
  この仕組みはあくまで「Web上の表示」を見ているため、100%の防止を保証するものではありません。
- チェック頻度（30分ごと）は `.github/workflows/monitor.yml` の `cron` を変更すれば調整できます。
  例：15分ごとにしたい場合は `*/15 * * * *`

## 出品準備機能（商品データ・写真の自動取得）

フジヤエービックの商品URLを入力すると、以下を自動で行います。
- 商品名・ブランド・ランク（コンディション）・JANコード・価格・特記事項を取得
- 商品写真をすべてダウンロード
- `listings.csv` に1行追加（eBayタイトル・eBay価格は空欄。ご自身で入力してください）

### 使い方
1. GitHubリポジトリの「Actions」タブを開く
2. 左側の「Fujiya Avic Listing Fetcher」を選択
3. 右側の「Run workflow」をクリック
4. `url` の欄にフジヤエービックの商品ページURLを貼り付けて実行
5. 実行が完了したら、その実行結果のページ（Summary）下部にある
   「fujiya-listing-◯◯」というアーティファクトから写真一式をzipでダウンロードできます
6. `listings.csv` にも商品データが1行追加されているので、リポジトリ側でも確認できます

### 制限事項
- 現状は1回の実行につき商品1点です（複数点まとめて処理したい場合はお知らせください。対応できます）
- JANコード・ランク・特記事項の抽出は、フジヤエービックのページ表記ゆれにより
  取得できない/ずれることがあります。何件か試してみて、うまく取れない項目があれば
  教えてください。抽出ロジックを調整します
- 価格・英語タイトル・商品説明は自動生成していません（ご要望があれば追加できます）
- アーティファクト（写真）は14日間で自動削除されます。早めにダウンロードしてください
